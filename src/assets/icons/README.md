# Icon Placeholder Files

This folder contains the extension icons.

Required icon sizes:

- icon16.png (16x16) - Toolbar/tab icon
- icon32.png (32x32) - Windows shortcut
- icon48.png (48x48) - Extensions page
- icon128.png (128x128) - Chrome Web Store

## Creating Icons

1. Design your icon at 128x128 pixels
2. Export in all sizes listed above
3. Use PNG format with transparency

For now, copy your existing `icon128.png` to this folder and create resized versions.
